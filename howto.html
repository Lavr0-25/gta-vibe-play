КАК ЭТО СДЕЛАНО

Инструменты, на которых собрана игра «Vibe Racer 2» (и весь конкурс)

ИИ и кодинг

  • Claude Code (Claude, Anthropic) — вся игра написана «вайбкодингом»: постановка задач текстом по шагам, код пишет агент, проверка — руками в браузере. Один HTML-файл целиком.
  • VS Code — редактор, Git + GitHub — версионирование.
  • Playwright — агент сам гоняет игру (старт, аварии, покупки) и ловит баги перед показом.

Картинки и звук

  • GigaChat (Сбер) — все спрайты: 6 машин с видом сверху, пальмы, здания, пруд, эстакада, логотип. Сгенерировано, фон снят скриптом, вшито в файл как base64 — игра работает без интернета.
  • Python + Pillow — конвейер картинок: повороты «носом вверх», хромакей, сборка логотипа с акцентом «GTA VI».
  • WebAudio (JavaScript) — звук нарисован кодом, без аудио файлов: мотор, сирена копов, хруст аварии, звон монет.

Сама игра (техника)

  • Canvas 2D — дорога, асфальт с трещинами (бесшовный тайл), машины, частицы.
  • Один HTML-файл без внешних запросов — можно скопировать и играть офлайн.
  • Спецификации (docs/specs/) ведутся вместе с кодом: по ним проект можно воссоздать с нуля.
